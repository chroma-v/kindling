---

Parse URL-safe filter strings, compile them to database queries (Drizzle ORM or
raw SQL), and compose interceptor pipelines for scoping, soft-delete, and audit
trails — with zero exceptions thrown.

```
?filter=status eq 'active' AND priority eq 'high'&sort=createdAt:desc&limit=50
```

## Install

```package-install
npm install @chromav/frizzle
```

Drizzle ORM is an *optional* peer dependency — needed only if you use the
Drizzle code generators (`@chromav/frizzle/drizzle`).

## A first query

```typescript
import { isSuccess } from "@chromav/frizzle";
import { compileFilter } from "@chromav/frizzle/drizzle";

const result = await compileFilter(
  "status eq 'active' AND priority eq 'high'",
  { status: "status", priority: "priority" }
);

if (isSuccess(result)) {
  const tasks = await db.query.tasks.findMany({ where: result.data });
}
```

Every function returns a `Result<T>` — a discriminated union of success or
error. Nothing throws, so error handling stays explicit and composable.
