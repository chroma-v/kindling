Packages for building data-driven screens on Drizzle/SQLite stacks. Extracted
from a working product rather than designed in the abstract — each one earns its
place by being used.

<CardGroup cols={2}>
  <Card title="Frizzle" icon="filter" href="/frizzle">

    Drizzle or raw SQL, and compose interceptor pipelines. Zero runtime
    dependencies, no exceptions thrown.
  </Card>
  <Card title="Sizzler" icon="database" href="/sizzler">

    snapshots.
  </Card>

## Install

```package-install
npm install @chromav/frizzle @chromav/sizzler
```

The published names are scoped. Internally — in the monorepo they're developed
in, and in this repo's own `packages/*` — they're just `frizzle` and `sizzler`;
the scope is applied only at publish time.

Entry points: `@chromav/frizzle`, `@chromav/frizzle/drizzle`,
`@chromav/frizzle/sql`, `@chromav/sizzler`, `@chromav/sizzler/node`.

## Vendoring instead

Both packages are self-contained — own build, own tests, own `exports` map. If
you'd rather not take an npm dependency, `git subtree add` the repo into your
monorepo, add `<prefix>/packages/*` to your npm `workspaces`, then
`npm install && npm run build`.
